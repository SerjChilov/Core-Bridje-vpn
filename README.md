# Core Bridje vpn

Открытый набор, чтобы поднять тот же VPN на новом сервере: VLESS + REALITY и подписка Happ. В репозитории нет адресов и ключей. Их создаёт `install.sh` на машине, где запускается установка.

В подписке имя **Core Bridge**, сервер внутри — **🇪🇸 Core Bridge Spain**. Российские сервисы, банки и MAX идут напрямую, остальной трафик через VPN, реклама блокируется.

## Установка

На чистом Ubuntu, от root:

```bash
git clone https://github.com/SerjChilov/Core-Bridje-vpn.git
cd Core-Bridje-vpn
bash install.sh
```

Скрипт ставит Xray, выпускает ключи, открывает REALITY на порту 8443 и печатает ссылку для Happ. Порт 8443 должен быть доступен снаружи. Повторный запуск не меняет уже созданные ключи.

Секреты остаются в `/etc/core-bridje/server.env`. Этот файл не нужно копировать в git.

## Правила туннеля

Списки лежат в `rules/`:

- `direct.txt` — напрямую
- `proxy.txt` — через VPN
- `block.txt` — блок
- `direct-ips.txt` и `proxy-ips.txt` — сети

Строка без префикса — это домен и все поддомены. Явные формы: `keyword:имя`, `full:имя`.

После правки снова запусти `bash install.sh` из каталога проекта и обнови подписку в Happ.
